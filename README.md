# Awesome Landing Page

A modern, responsive landing page template built with semantic HTML, CSS variables, and vanilla JavaScript.

## Features
- Responsive layout
- Accessible markup and keyboard-friendly navigation
- Mobile menu toggle and smooth scrolling
- Minimal dependencies (no build step required)

## View locally
1. Clone the repository:

   git clone https://github.com/xyztnecniV/awesome-landing-page.git

2. Open index.html in your browser:

   open index.html

No server needed — files are static.
